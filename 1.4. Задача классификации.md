## 1. Формальная постановка задачи классификации
### 1.1. Бинарная
### Вероятностная модель 
* $\boldsymbol{\xi} \in \mathbb R^p$ – случайный вектор признаков 
* $\eta \in \mathcal Y$  – ДСВ, метка класса. В случае бинарной классификации $\mathcal Y = \set{-1, + 1}$
* $P(\boldsymbol{\xi}, \eta)$ – их совместное распределение 

**Дано:**
Выборка $\left( X_{\text{train}}, \mathbf{y}_{\text{train}} \right)$ – $N$ реализаций случайного вектора $(\boldsymbol{\xi}, \eta)$. По выборке необходимо построить классификатор: $$f : \mathbb R^p \to \mathcal Y$$
### Линейная модель классификации 
В общем случае линейный классификатор имеет вид $$f(\mathbf x_i, \mathbf w)= (\operatorname{sign} \left< \mathbf w, \mathbf x_i\right> + w_0)$$
Где $\mathbf w$ – вектор весов признаков, а $w_0$ – некоторый сдвиг, который позволяет не попасть в нулевое значение.

Для упрощения записи будем рассматривать классификатор в следующей форме: добавим в матрицу объектов $\mathbf X$ вектор-столбец единиц, получив вхождение сдвига $w_0$ в $\mathbf w$ 
$$f(\mathbf x_i, \mathbf w)= \operatorname{sign} \left< \mathbf w, \mathbf x_i\right> $$
### Отступ (margin) и пороговая функция потерь
Для оценки качества классификации вводится понятие отступа (margin) на $i$-ом объекте:
$$M_i = \left< (\mathbf w, \mathbf x_i), \mathbf x_i\right>y_i$$
Отступ характеризует "расстояние" (степень уверенности модели) между реальным значением класса $y_i$ и предсказанным значением (скалярным произведением до взятия знака)
* Если $M_i > 0$, то знак предсказания совпал со знаком $y_i$ (предсказание верно)
* Если $M_i < 0$, считаем, что объект классифицирован неверно 

Для подсчета ошибок на выборке используем **пороговую функцию потерь**:
$$\mathcal L_{thresh}(M_i) = [M_i < 0] = \begin{cases} 1, \quad M_i < 0 \\ 0, \quad M_i \ge 0 \end{cases}$$
Тогда исходная задача классификации сводится к минимизации числа ошибок на обучающей выборке (эмпирического риска):
$$\sum_{i=1}^n [M_i < 0] \to \min$$
### Переход к непрерывной оптимизации
Пороговая функция потерь $\mathcal L_{thresh}$ – разрывная и ступенчатая, очевидно недифференцируема. 

В связи с этим пороговую функцию заменяют на непрерывную и гладкую функцию $\mathcal L(M_i)$, которая выступает верхней оценкой для пороговой функции:
$$\mathcal L_{thresh} (M_i) = [M_i <0] \le \mathcal L(M_i)$$
Знак минус у отступа рассматриваем как штраф за неверную классификацию. Итоговая задача оптимизации формулируется как минмизация суммарного штрафа по всей выборке:
$$\sum_{i=1}^n \mathcal L(M_i) \to \min_{\mathbf w}$$

### 1.2. Многоклассовая
#### 1.2.1. Классические (OvR, OvO)
За основу берется бинарная классификация:
- **One-vs-Rest**:
	Обучается $K$ (по каждой на класс) базовых бинарных классифкаторов, при обучении $i$-й модели объекты $i$-го класса помечаются как положительный класс ($+1$), а объекты всех остальных классов — как отрицательный класс ($-1$).
	
	После, инференс происходит следующим образом: новый объект оценивает каждая из $K$ моделей, победителем признается класс, чья модель, выдала наибольшую вероятность (или score) принадлежности к "родному" классу. 
	
	Главный минус: серьезное влияние проблемы баланса/дисбаланса. К примеру, если классы сбалансированы идеально, то каждая из моделей выдаст вероятность ровно $\dfrac{1}{K}$

- **One-vs-One**:
	Обучается $\dfrac{K(K-1)}{2}$ базовых моделей. Процесс обучения выглядит так: берутся два класса, остальные отбрасываются, строится бинарная граница между классом 1 и классом 2.
	
	На инференсе объект подается каждому классификатору, он "голосует" за один из двух своих классов. Финальный вердикт выносится по большинству голосов. В случае "ничьей" выбирается класс с наибольшей суммарной уверенностью моделей.
	
	Склонность к переобучению выше, чем у OvR т. к. больше мелких подвыборок.

#### 1.2.2. Прямое предсказание вероятностей классов
Формальное задание использует концепт логистической регрессии. Вместо разделения задачи на несколько независимых подзадач, модель обучается оценивать принадлежность объекта ко всем классам одновременно. 

Наиболее частый пример – мультиномиальная логистическая регрессия. Логистическая регрессия обобщается на $K$ классов. На выходном слое модели используется функция **Softmax**, которая превращает выходы модели (логиты) в полноценное распределение вероятностей (сумма равна 1). Обучение идет через функцию потерь **категориальная кросс-энтропия** (Categorical Cross-Entropy).

Другие примеры – KNN, деревья решений и случайный лес.

#### 1.2.3. Иерархическая классификация
Классы организуются в виде древовидной структуры или направленного ациклического графа (DAG).

- **Как это работает:** Модель сначала определяет укрупненную категорию объекта (например, _«Животное»_ или _«Растение»_), а затем спускается ниже по дереву для уточнения конкретного класса (_«Млекопитающее»_ $\rightarrow$ _«Кошачьи»_ $\rightarrow$ _«Тигр»_).
- **Плюс:** Эффективно, когда классов очень много (тысячи) и между ними есть логическая вложенность.

#### 1.2.4. Другие (без подробностей)
- ECOC — Error-Correcting Output Codes: обобщение бинарного подхода, превращающее задачу в теорию кодирования информационных сигналов. Каждому классу присваивается уникальный двоичный код определенной длины. Обучается несколько бинарных классификаторов (каждый отвечает за один бит в коде). При предсказании модель получает строку битов и сопоставляет её с кодом того класса, к которому она ближе всего по расстоянию Хэмминга.
- Метрическое обучение (Metric Learning): задача классификации переводится в задачу геометрии пространства признаков.

## 2. Метрики
### 2.1. Матрица ошибок (confusion matrix) 
Пусть есть 2 класса и алгоритм, предсказывающий принадлежность каждого объекта к одному из классов

|                     | $\mathbf y =1$        | $\mathbf{y}=0$        |
| :------------------ | :-------------------- | :-------------------- |
| $\mathbf{\hat y}=1$ | $TP$ (True Positive)  | $FP$ (False Positive) |
| $\mathbf{\hat y}=0$ | $FN$ (False Negative) | $TN$ (True Negative)  |
Ошибки классификации бывают двух видов: $FN$ и $FP$.

***
### 2.2. Accuracy
Очевидная, почти нигде не используемая метрика, отображающая долю правильных ответов:
$$\operatorname{Accuracy}=\dfrac{TP+TN}{TP+TN+FP+FN}$$
Бесполезна в задачах с неравными классами, так как иногда по этой метрике эффективнее собрать все в один класс.

***
### 2.3. Precision, Recall, F-метрика
Для оценки работы алгоритма на каждом из классов по отдельности вводим метрики точности ($precision$) и полноты ($recall$):
$$\operatorname{Precision}= \dfrac{TP}{TP+FP}$$
$$\operatorname{Recall} = \dfrac{TP}{TP+FN}$$
$Precision$ можно интерпретировать как долю объектов, названных классификатором положительными, и при этом действительно являющихся положительными.
$Recall$ показывает какую долю объектов положительного класса из всех объектов положительного класса нашел алгоритм.

Именно введение $precision$ не позволяет нам записывать все объекты в один класс (такая проблема появляется в $accuracy$), так как в этом случае мы получаем рост уровня $FP$. 

$Recall$ демонстрирует способность алгоритма обнаруживать данный класс вообще, а $precision$ – способность отличать этот класс от других.

Обе этих метрики, в отличие от $accuracy$ не зависят от (дис-)баланса классов, а потому применимы в условиях несбалансированных выборок.

**$F$-мера** (в общем случае $F_{\beta}$) – среднее гармоническое $precision$ и $recall$: $$F_{\beta}=\left(1+\beta^2\right)\dfrac{\operatorname{Precision} \cdot \operatorname{Recall}}{\left(\beta^2\cdot\operatorname{Precision} \right)+\operatorname{Recall}}$$
$\beta$ в данном случае определяет вес точности в метрике. При $\beta = 1$ $F$-мера достигает максимума при полноте и точности, равными единице, и близка к нулю, если один из аргументов близок к нулю.

***

### 2.4. AUC-ROC и AUC-PR

**AUC-ROC** (или ROC AUC) – это площадь (Area Under Curve) под кривой ошибок (Receiver Operating Characteristic curve). Данная кривая представляет собой линию от $(0,0)$ до $(1,1)$ в координатах $TPR$ (True Positive Rate) и $FPR$ (False Positive Rate):
$$TPR = \dfrac{TP}{TP+FN}$$
$$FPR = \dfrac{FP}{FP+TN}$$
$TPR$ – это полнота, а $FPR$ показывается какую долю из объектов negative класса алгоритм предсказал неверно. В идеальном случае, когда классификатор не делает ошибок ($FPR = 0, \, TPR = 1$), мы получаем $AUC = 1$. В противном случае, когда классификатор выдает вероятности классов случайно, $AUC \to 0,5$, так как классификатор будет выдавать одинаковое количество $TP$ и $FP$.

## 3. Дисбаланс, пересечение, выбросы 
### 3.1. Дисбаланс 
Наивно можно добавить в выборку данные так: случайным образом выбрать наблюдения из класса меньшинства и добавить их в набор данных, пока мы не достигнем баланса между большинством и классом меньшинства. Проблема такого подхода в том, что несмотря на номинальное увеличение числа экземпляров миноритарного класса, мы сталкиваемся с отсутствием добавления "новой" информации. Новые данные не содержат больше о характеристиках класса, чем старые.

### 3.1.1. SMOTE+
Метод увеличения числа примеров миноритарного класса (Synthetic Minority Over-sampling Technique) SMOTE – это алгоритм предварительной обработки данных, также используемый для устранения дисбаланса классов в датасете.

В общих чертах: алгоритм находит разность между данным образцом и его ближайшим соседом. Эта разность умножается на случайное число в интервале от 0 до 1, затем полученное значение добавляется к данному образцу для формирования нового в пространстве признаков. Подобные действия продолжаются со следующим ближайшим соседом до заданного пользователем количества образцов. 

**Расширения SMOTE:**
1. BorderlineSMOTE. Вместо избыточной выборки между всеми наблюдениями меньшинств, алгоритм стремится увеличить количество наблюдений меньшинств, которые граничат с наблюдениями большинства. Цель здесь – дать классификатору возможность более четко различать эти пограничные наблюдения.
2. SVMSMOTE: использует алгоритм машины опорных векторов, чтобы сгенерировать новые наблюдения вблизи границы между классами меньшинства и большинства.

Визуализация SMOTE:
1. Берем индивида и вычисляем $k$ ближайших соседей. Затем выбираем случайного ближайшего соседа из $k$ ближайших соседей. ![[Pasted image 20261026211353.png]]

2. Вычисляем разность между двумя точками и умножаем ее на случайное число от 0 до 1. Получаем синтезированный образец вдоль линии между двумя точками. ![[Pasted image 20261026211458.png]]
3. Выбираем m соседей для этого индивида и повторяем процедуру дублирования. m подбирается из соотношения классов. Для каждого из исходных индивидов повторяем весь алгоритм для достижения равного количества индивидов в классах.

### 3.1.2. Tomek Links
Пусть экземпляры $E_i$ и $E_j$ принадлежат различным классам. $d(E_i, E_j)$ – расстояние между указанными примерами. Пара $(E_i, E_j)$ называется связью Томека, если не найдется ни одного примера $E_t$, такого, что будет справедлива совокупность неравенств: 
$$\begin{cases}d(E_i, E_t) < d(E_i, E_j) \\ d(E_j, Et) < d(E_i, E_j)\end{cases}$$
Согласно данному подходу, все индивиды из большей группы, входящие в связи Томека, должны быть удалены из датасета. Способ хорошо подходит для удаления данных, которые рассматриваются как "зашумляющие".

### 3.3. Выбросы 
Выбросы классификации делятся на:
1. Выбросы в признаках $\mathbf{x}$ (аномальные координаты, leverage points).
2. Выбросы в метках (Label Noise / шум переворота метки).

* **Математическая чувствительность суррогатных функций потерь $\mathcal{L}(M)$:**
  Если объект ошибочен и далеко за разделяющей полосой ($M_i \ll 0$):
  * **AdaBoost (Exponential Loss $\mathcal{L} = e^{-M}$):** Штраф растет **экспоненциально**. Алгоритм фокусирует все свои ресурсы на попытке классифицировать единичный шумный объект с глубоким отрицательным отступом, что катастрофически ломает разделяющую поверхность.
  * **Log-Loss ($\mathcal{L} = \ln(1 + e^{-M})$):** Асимптотически растет **линейно** (при $M \to -\infty$, $\mathcal{L} \approx -M$). Менее чувствителен, чем экспоненциальный, но шумный объект все равно вносит бесконечно растущий вклад в градиент.
  * **SVM (Hinge Loss $\mathcal{L} = \max(0, 1 - M)$):** Линейный рост штрафа. Выбросы становятся опорными векторами с множителем Лагранжа $\alpha_i = C$ (константа регуляризации ограничивает максимальное воздействие одной точки).

## 4. Критерии выбора моделей и метрик 
### 4.1. Выбор метрики в зависимости от прикладной постановки

Выбор метрики эквивалентен фиксации функции потерь бизнеса:
$$\text{Cost} = C_{\mathrm{FP}} \cdot FP + C_{\mathrm{FN}} \cdot FN$$

| Условие задачи | Рекомендуемая метрика | Математическое обоснование |
| :--- | :--- | :--- |
| **Сбалансированные классы, равнозначные ошибки** | $\operatorname{Accuracy}$ | Оценивает общее число ошибок $TP+TN$. Имеет прозрачный статистический смысл доли совпадений. |
| **Критична цена пропуска ($C_{\mathrm{FN}} \gg C_{\mathrm{FP}}$)** (онкоскрининг, обнаружение дефектов) | $\operatorname{Recall}$ или $F_\beta$ ($\beta > 1$, напр. $F_2$) | Штрафует за $FN$. $F_2$ придает полноте вес в $2^2 = 4$ раза больший, чем точности. |
| **Критична цена ложной тревоги ($C_{\mathrm{FP}} \gg C_{\mathrm{FN}}$)** (спам-фильтры, блокировка транзакций) | $\operatorname{Precision}$ или $F_\beta$ ($\beta < 1$, напр. $F_{0.5}$) | Штрафует за ложные срабатывания $FP$, предотвращая блокировку легитимных операций. |
| **Сильный дисбаланс, оценка качества ранжирования** (fraud detection, кликабельность) | $\operatorname{PR\text{-}AUC}$ | Не маскирует ошибки большим количеством истинно отрицательных объектов ($TN$), устойчива к смещению пропорций классов. |
| **Нужна вероятностная интерпретация** (выдача кредита с оценкой вероятности дефолта) | $\operatorname{Log\text{-}Loss}$ (Кросс-энтропия), Brier Score | Являются **строго согласованными (strictly proper) скоринговыми правилами**: их теоретический минимум достигается тогда и только тогда, когда выданная моделью вероятность в точности равна истинной условной вероятности $\hat{p}(\mathbf{x}) = \mathbb{P}(y=1 \mid \mathbf{x})$. |

### 4.2. Критерии выбора семейства моделей

1. **Линейные модели (Логистическая регрессия, Линейный SVM):**
   * *Критерии выбора:* Высокая размерность при умеренном $n$ ($p \gg n$, текстовые мешки слов, разреженные данные OHE); требование строгой интерпретируемости (веса как логиты шансов); базовый бейзлайн.
2. **Метрические алгоритмы ($k$-NN):**
   * *Критерии выбора:* Сложная геометрия разделяющей границы при низкой размерности ($p < 15$ во избежание проклятия размерности); компактные выборки (инференс $\mathcal{O}(n p)$).
3. **Решающие деревья и ансамбли (Random Forest, Gradient Boosting — XGBoost/CatBoost):**
   * *Критерии выбора:* Табличные гетерогенные данные; наличие нелинейных взаимодействий фичей высокой степени; устойчивость к мультиколлинеарности и монотонным трансформациям масштаба; отсутствие нормальности распределений. RF предпочтителен против высокого разброса (variance), бустинг — против высокого смещения (bias).
4. **Нейронные сети (Deep Learning):**
   * *Критерии выбора:* Неструктурированные данные (изображения, аудио, тексты), где локальные зависимости и инвариантности к сдвигам моделируются пространственными/последовательными архитектурами (CNN, Transformers). Требуют колоссального объема данных ($n \gg 10^5$).
