## 1. Постановка задачи Support Vector Regression (SVR)

В классической постановке регрессии задана обучающая выборка $\{(\mathbf{x}_1, y_1), \dots, (\mathbf{x}_n, y_n)\}$, где $\mathbf{x}_i \in \mathbb{R}^p$, а отклик непрерывен: $y_i \in \mathbb{R}$.

Ищется линейная функция:
$$f(\mathbf{x}) = \langle \mathbf{w}, \mathbf{x} \rangle + b$$
(или нелинейная $f(\mathbf{x}) = \langle \mathbf{w}, \psi(\mathbf{x}) \rangle + b$ в спрямляющем пространстве), удовлетворяющая двум фундаментальным критериям:
1. **Максимальная гладкость (минимальная сложность):** минимизируется евклидова норма весов $\frac{1}{2}\|\mathbf{w}\|^2$, что предотвращает резкие осцилляции функции.
2. **Толерантность к ошибкам:** допускаются отклонения предсказания от истинных значений $y_i$ в пределах фиксированной погрешности $\varepsilon > 0$.

---

## 2. $\varepsilon$-нечувствительная функция потерь и $\varepsilon$-трубка

Ключевой концепт метода опорных векторов в регрессии — **$\varepsilon$-нечувствительная функция потерь Вапника ($\varepsilon$-insensitive loss)**:

$$L_\varepsilon(y, f(\mathbf{x})) = |y - f(\mathbf{x})|_\varepsilon = \max\big(0, |y - f(\mathbf{x})| - \varepsilon\big) = \\\\ = \begin{cases} 
0, & |y - f(\mathbf{x})| \le \varepsilon \\ 
|y - f(\mathbf{x})| - \varepsilon, & |y - f(\mathbf{x})| > \varepsilon 
\end{cases}$$

В сравнении с Huber:

[![Huber loss and ϵ$$ \epsilon $$‐insensitive loss. | Download Scientific  Diagram](https://www.researchgate.net/publication/403911351/figure/fig2/AS:11431282068666898@1776408561190/Huber-loss-and-e-epsilon-insensitive-loss.png)

### Геометрический смысл ($\varepsilon$-трубка):
Вокруг регрессионной гиперплоскости $f(\mathbf{x})$ строится «трубка» (полоса) полушириной $\varepsilon$:
$$f(\mathbf{x}) - \varepsilon \le y \le f(\mathbf{x}) + \varepsilon$$
* **Внутри трубки ($|y_i - f(\mathbf{x}_i)| \le \varepsilon$):** ошибка считается допустимым естественным шумом измерения и **штрафуется нулем**.
* **Вне трубки ($|y_i - f(\mathbf{x}_i)| > \varepsilon$):** ошибка штрафуется строго **линейно** (в отличие от квадратичного штрафа в МНК/OLS).

## 3. Прямая задача оптимизации (Primal SVR)

Поскольку ошибки могут происходить в обе стороны (объект лежит либо строго выше трубки, либо строго ниже), для каждого объекта вводятся **два набора ослабляющих переменных (slack variables)**:
* $\xi_i \ge 0$ — величина заступа объекта **выше** верхней границы трубки;
* $\xi_i^* \ge 0$ — величина заступа объекта **ниже** нижней границы трубки.

$$\begin{cases}
\dfrac{1}{2}\|\mathbf{w}\|^2 + C \sum_{i=1}^n (\xi_i + \xi_i^*) \to \min_{\mathbf{w}, b, \boldsymbol{\xi}, \boldsymbol{\xi}^*} \\\\
y_i - (\langle \mathbf{w}, \mathbf{x}_i \rangle + b) \le \varepsilon + \xi_i, \quad i = 1, \dots, n \\\\
(\langle \mathbf{w}, \mathbf{x}_i \rangle + b) - y_i \le \varepsilon + \xi_i^*, \quad i = 1, \dots, n \\\\
\xi_i \ge 0, \quad \xi_i^* \ge 0, \quad i = 1, \dots, n
\end{cases}$$

где $C > 0$ — гиперпараметр регуляризации, определяющий баланс между гладкостью функции регрессии и суммарным выходом точек за границы $\varepsilon$-трубки.

## 4. Двойственная задача оптимизации (Dual SVR)

### 4.1. Лагранжиан и условия ККТ
Введем двойственные множители Лагранжа: 
* $\alpha_i \ge 0$ и $\alpha_i^* \ge 0$ — для основных ограничений трубки;
* $\eta_i \ge 0$ и $\eta_i^* \ge 0$ — для ограничений неотрицательности $\xi_i, \xi_i^*$.

Условия стационарности Лагранжиана по прямым переменным:
1. $\nabla_{\mathbf{w}} \mathcal{L} = \mathbf{0} \implies \mathbf{w} = \sum_{i=1}^n (\alpha_i - \alpha_i^*) \mathbf{x}_i$
   
2. $\dfrac{\partial \mathcal{L}}{\partial b} = 0 \implies \sum_{i=1}^n (\alpha_i - \alpha_i^*) = 0$
   
3. $\dfrac{\partial \mathcal{L}}{\partial \xi_i} = 0 \implies C - \alpha_i - \eta_i = 0 \implies 0 \le \alpha_i \le C$
   
4. $\dfrac{\partial \mathcal{L}}{\partial \xi_i^*} = 0 \implies C - \alpha_i^* - \eta_i^* = 0 \implies 0 \le \alpha_i^* \le C$

### 4.2. Формулировка двойственной задачи
Подставляя стационарные точки обратно в Лагранжиан, получаем выпуклую задачу квадратичного программирования:

$$\begin{cases}
Q(\boldsymbol{\alpha}, \boldsymbol{\alpha}^*) = -\dfrac{1}{2}\sum_{i=1}^n \sum_{j=1}^n (\alpha_i - \alpha_i^*)(\alpha_j - \alpha_j^*) \langle \mathbf{x}_i, \mathbf{x}_j \rangle - \varepsilon \sum_{i=1}^n (\alpha_i + \alpha_i^*) + \sum_{i=1}^n y_i(\alpha_i - \alpha_i^*) \to \max_{\alpha,\alpha^*} \\\\
\sum_{i=1}^n (\alpha_i - \alpha_i^*) = 0 \\\\
0 \le \alpha_i \le C, \quad 0 \le \alpha_i^* \le C, \quad \forall i = 1, \dots, n
\end{cases}$$

*(При использовании ядерного перехода скалярное произведение просто заменяется на ядро: $\langle \mathbf{x}_i, \mathbf{x}_j \rangle \mapsto K(\mathbf{x}_i, \mathbf{x}_j)$).*

### 4.3. Решающее правило и разреженность (Sparsity)
По условиям дополняющей нежесткости:
$$\alpha_i \Big( \varepsilon + \xi_i - y_i + \langle \mathbf{w}, \mathbf{x}_i \rangle + b \Big) = 0$$
$$\alpha_i^* \Big( \varepsilon + \xi_i^* + y_i - \langle \mathbf{w}, \mathbf{x}_i \rangle - b \Big) = 0$$

* Объект не может находиться одновременно выше и ниже трубки, поэтому для любого объекта **как минимум один из множителей $(\alpha_i, \alpha_i^*)$ строго равен нулю**: $\alpha_i \cdot \alpha_i^* = 0$.
* **Опорные векторы регрессии:** Для всех объектов, лежащих строго **внутри** $\varepsilon$-трубки ($|y_i - f(\mathbf{x}_i)| < \varepsilon$), ограничения выполняются со строгим неравенством, следовательно:
  $$\alpha_i = 0 \quad \text{и} \quad \alpha_i^* = 0$$
  В формировании модели участвуют **только объекты, лежащие на границе трубки или за её пределами**!

Итоговый прогноз для нового объекта:
$$f(\mathbf{x}) = \sum_{i \in \mathrm{SV}} (\alpha_i - \alpha_i^*) K(\mathbf{x}_i, \mathbf{x}) + b$$

## 5. Роль параметров $C$ и $\varepsilon$

```
          Широкая eps-трубка                        Узкая eps-трубка
               .--------.                                .----.
     y_i      /          \                     y_i      /      \
      *      /     *      \                     *      /   *    \
     --------=============--------             --------========--------
            \     *      /                            \        /
             '----------'                              '------'
      Мало опорных векторов                      Много опорных векторов
```

### 5.1. Роль параметра $\varepsilon$ (Ширина зоны нечувствительности)
* **Большое $\varepsilon$:** Трубка широкая. Большинство объектов выборки попадает внутрь трубки, их множители $\alpha_i = \alpha_i^* = 0$.
  * *Следствие:* Модель предельно **разреженна (мало опорных векторов)**, функция регрессии максимально сглажена, высокая скорость инференса. 
  * *Риск:* **Недообучение (High Bias)**, игнорирование важных локальных зависимостей.
* **Малое $\varepsilon \to 0$:** Трубка сужается в линию. Почти все точки оказываются вне трубки.
  * *Следствие:* Число опорных векторов стремится к $n$ (разреженность теряется), алгоритм штрафует даже микроскопический шум.
  * *Риск:* **Переобучение (High Variance)**.

### 5.2. Роль параметра $C$ (Штраф за выход из трубки)
* **Большое $C \to \infty$:** Запрещает точкам далеко отклоняться от $\varepsilon$-трубки. Модель пытается изогнуть разделяющую поверхность (особенно при RBF-ядре) так, чтобы охватить все выбросы. Риск оверфиттинга.
* **Малое $C \to 0$:** Приоритет отдается минимизации нормы $\|\mathbf{w}\|_2$. Функция регрессии вырождается в жесткую прямую линию, толерантную к большим невязкам.

## 6. Принципиальные отличия SVR от линейной регрессии (OLS/Ridge)

| Критерий | Классическая линейная регрессия (OLS / Ridge) | Метод опорных векторов (SVR) |
| :--- | :--- | :--- |
| **Функция потерь** | **Квадратичная (MSE):** $\mathcal{L} = (y - \hat{y})^2$ | **$\varepsilon$-нечувствительная:** $\mathcal{L} = \max(0, \|y - \hat{y}\| - \varepsilon)$ |
| **Чувствительность к выбросам** | **Крайне высокая:** квадратичный рост штрафа вынуждает гиперплоскость резко смещаться к аномалиям | **Робастная (устойчивая):** линейный штраф за пределами трубки ограничивает влияние далеких выбросов |
| **Влияние шума малой амплитуды** | Штрафуется даже бесконечно малый шум ($e^2 > 0$) | **Игнорируется полностью** (если шум $\le \varepsilon$) |
| **Разреженность решения** | **Отсутствует:** каждый из $n$ объектов обучающей выборки вносит ненулевой вклад в прогноз ($\hat{\mathbf{y}} = \mathbf{H}\mathbf{y}$) | **Высокая:** точки внутри трубки отбрасываются, прогноз зависит исключительно от небольшого подмножества опорных векторов |
| **Нелинейные зависимости** | Требует ручной генерации признаков или полиномов | Естественно обобщается через **Kernel Trick** на бесконечномерные пространства (RBF-SVR) |
| **Вычислительная сложность** | OLS: $\mathcal{O}(np^2 + p^3)$ — аналитическое обращение матрицы | Решение квадратичной задачи QP: от $\mathcal{O}(n^2)$ до $\mathcal{O}(n^3)$ — сложнее на больших выборках |
