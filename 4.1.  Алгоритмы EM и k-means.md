## 1. k-means
Формальную постановку задачи кластеризации можно посмотреть [[1.5. Задача кластеризации|здесь]].

Метод k-means осуществляет декомпозицию набора данных, состоящего из n наблюдений, на k кластеров с заранее неизвестными параметрами. При этом выполняется поиск центроидов - максимально удаленных друг от друга центров сгущений точек $C_k$ с минимальным разбросом внутри каждого кластера.

В качестве меры близости выбрано евклидово расстояние:
$$d(\mathbf x_i, \mathbf x_{i'}) = \sum_{j=1}^p(x_{ij}-x_{i'j})^2=\lVert\mathbf x_i-\mathbf x_{i'} \rVert^2$$
Основная идея алгоритма заключается в минимизации меры близости между индивидами внутри одного кластера:
$$\Large\min_{C_1,\dots,C_k}\left\{\sum_{l=1}^k\dfrac{1}{|C_l|}\sum_{i,\,i'\in C_l}\lVert\mathbf x_i -\mathbf x_{i'}\rVert^2 \right\}$$
### 1.1. Алгоритм обновления центроидов
1. Выбираем начальное приближение центров кластеров $\mu_1,\dots,\mu_k$ случайным образом
2. Соотносим каждый объект к ближайшему центру (аналог $E$-шага) $$C(i)=\arg \min_{0\le j\le k} \lVert x_i-\mu_j \rVert^2$$
3. Для каждого кластера $C_j$ пересчитываем центры $\mu_j$ как выборочное среднее индивидов, которые были отнесены к этому кластеру (аналог $M$-шага)
4. Повторяем шаги 2 и 3, пока принадлежность к кластерам не перестанет изменяться.

Иными словами, делаем следующее: инициализируем центры, затем разделяем индивиды по ближайшему центру кластера, перевычисляем каждый из центров, и если ничего не изменилось, останавливаемся, если изменилось, то повторяем.

### 1.2. Комментарии к $k$-means
#### 1.2.1. Сложность и возможные оптимизации
Средняя сложность определяется как $O(knT)$, где $k$ – количество кластеров, $n$ – количество индивидов, а $T$ – количество итераций до сходимости.

В наихудшем случае определяется как $O(n^{k+2 /p})$, где $p$ – количество признаков.
На практике $k$-means – один из самых быстрых доступных алгоритмов кластеризации, но имеет склонность к попаданию в локальные минимумы, поэтому бывает полезно перезапустить его несколько раз.

При больших $n$ целесообразно использовать модификацию MiniBatchKMean, которая выполняет обновления позиции центров с помощью мини-пакетов, а не всей выборки. При больших $p$ целесообразно уменьшить размерность пространства признаков с помощью АГК.

#### 1.2.2. Связь $k$-means и $EM$-алгоритма
Алгоритм k-средних является частным случаем для гауссовой смеси распределения с диагональными ковариационными матрицами, у которых одинаковые значения на диагоналях.

В таком случае:
- На Е-шаге мы не считаем вероятности gij принадлежности i-го объекта j-ому кластеру, а приписываем каждый объект одному кластеру (вероятность принадлежности будет равна $0$ или $1$);
- Форма кластеров не настраивается: они все являются сферическими.

#### 1.2.3. Достоинства и недостатки
- Достоинства:
  1. Простота реализации 
  2. Алгоритм очень гибкий
  3. Существует множество модификаций

- Недостатки: 
  1. Кластеризация очень сильно зависит от начального приближения
     Выгодно брать максимально удаленные друг от друга центры. Неудачный их выбор может привести к плохому результату. Для решения можно либо провести кластеризацию с несколькими начальными приближениями и выбрать лучший вариант, либо использовать эвристику KMeans++: первый центр выбираем случайно из равномерного распределения на точках выборки, а каждый следующий центр выбираем из случайного распределения на объектах выборки, в котором вероятность выбрать объект пропорциональна квадрату расстояния от него до ближайшего к нему центра кластера.
  2. Кластеризация может быть неадекватной, если изначально выбрано неверное число кластеров
  3. Необходимость самостоятельно подбирать количество кластеров
     Подбирать число кластеров можно либо с помощью коэф. силуэта, либо с помощью метода локтя, который рассматривает характер изменения внутригруппового разброса с увеличением числа групп $k$. На каком-то этапе снижение этой дисперсии замедляется, на графике это происходит в точке, которую называют "локтем", что аналогично "каменистой осыпи" в АГК.
  4. Только сферическая форма кластеров.

## 2. $EM$-алгоритм
Один из вариантов формализовать задачу кластеризации – это сделать предположение о статистическом распределении данных. Затем задача будет состоять в поиске параметров этого распределения. Предположим, что модель данных состоит из $k$ смеси распределений. Пусть $\omega_1, \dots, \omega_k$ - априорные вероятности появления объектов из соответствующих кластеров, $p_1(x), \dots, p_k(x)$ - плотности распределения признаков внутри кластеров. Тогда плотность распределения сразу для всех кластеров равна взвешенной сумме плотностей по каждому кластеру: $$p(x)=\sum_{i=1}^k\omega_i\cdot p_i(x)$$
Поставим задачу разделения смеси распределений, оценим по выборке $\omega_1, \dots, \omega_k$ и $p_1(x), \dots, p_k(x)$. Это позволит оценить вероятность принадлежности индивида к разным кластерам и решить к какому кластеру его отнести. Часто рассматриваются случаи, когда распределения в смеси принадлежат одному семейству распределений (например, нормальному), но с разными наборами параметров для каждого кластера.
$$p_i(x)=\varphi(\theta_i \, ; x)$$
Согласно ММП: $$\omega, \theta=\arg\max_{\omega,\theta}\sum_{i=1}^n \ln p(x_i)=\arg\max\sum_{i=1}^n\ln\sum_{j=1}^k\omega_j \cdot \varphi(\theta_j \,;x_i)$$
Максимизация логарифма суммы достаточно сложна, поэтому задача не решается напрямую с помощью ММП. Для максимизации логарифма функции правдоподобия применяется $EM$-алгоритм. Это итеративный алгоритм, состоящий из двух шагов, в котором на первом шаге задаются некоторые значения параметров, а затем, с каждой итерацией, уточняются. 

### 2.1. $E$-шаг
В начале работы алгоритма задаем значения параметров $\omega, \theta = (\omega_1. \dots, \omega_k; \theta_1, \dots, \theta_k)$, и подставляя их, рассчитываем скрытые переменные.
Скрытые переменные $h_{ij}=\mathbb P(\theta_j\, |\, x_i)$ – это вероятность того, что индивид $x_i$ принадлежит $j$-ой смеси. Находим их по формуле Байеса: $$\Large h_{ij}=\dfrac{\omega_j \cdot \varphi(\theta_j\,;x_i)}{\sum_{s=1}^k \omega_s \cdot \varphi(\theta_s\,;x_i)}$$
Для любого индивида $\sum_{j=1}^k h_{ij}=1$.

### 2.2. $M$-шаг
На этом шаге будут рассчитываться значения параметров, которые мы ищем, используя скрытые параметры, полученные на предыдущем шаге. Решение методом Лагрнанжа для максимизации (с ограничением $\sum_{j=1}^k \omega_j=1$) дает оценку для параметров: 
$$\omega_j=\dfrac{1}{n}\sum_{i=1}^n h_{ij}$$
$$\theta_j=\arg \max_{\theta}\sum_{i=1}^n h_{ij}\ln\varphi(\theta;x_i)$$
Таким образом, параметры будут уточняться на каждом шаге.

### 2.3. Комментарии к $EM$
Если сделать предположение о том что классы принадлежат семейству нормальных распределений, то параметрами модели являются математическое ожидание и ковариационная матрица. Если не делать никаких предположений о ковариациях использование общей модели может быть весьма затруднительно, проблема заключается в большом количестве параметров, которые необходимо оценить. 

Ковариационные матрицы описывают геометрические характеристики кластеров, а именно объем, форму и ориентацию кластера. Общая модель предполагает, что все эти геометрические характеристики различны для каждого кластера. Однако, оценка плотности смеси, состоящей из кластеров одинаковой формы или ориентации, намного проще. Поэтому, сделав предположения о ковариационных матрицах, можно существенно облегчить задачу.

### 2.4. Смеси гауссовских распределений (GMM — Gaussian Mixture Models)

В случае, когда распределения внутри кластеров являются многомерными нормальными:
$$\varphi(\theta_j \,;\, \mathbf{x}) = \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_j, \mathbf{\Sigma}_j) = \frac{1}{(2\pi)^{p/2} |\mathbf{\Sigma}_j|^{1/2}} \exp\left( -\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu}_j)^T \mathbf{\Sigma}_j^{-1} (\mathbf{x} - \boldsymbol{\mu}_j) \right)$$
где параметрами $j$-го кластера выступают математическое ожидание $\boldsymbol{\mu}_j \in \mathbb{R}^p$ и ковариационная матрица $\mathbf{\Sigma}_j \in \mathbb{R}^{p \times p}$.

#### Аналитический вид формул на M-шаге для Гауссиан:
Обозначим эффективное число объектов, отнесенных к $j$-му кластеру, как:
$$N_j = \sum_{i=1}^n h_{ij}$$

Максимизация функции правдоподобия дает замкнутые формулы пересчета параметров:
1. **Априорные веса компонент (доли кластеров):**
   $$\omega_j = \frac{N_j}{n} = \frac{1}{n}\sum_{i=1}^n h_{ij}$$
2. **Центры кластеров (математические ожидания):**
   $$\boldsymbol{\mu}_j = \frac{1}{N_j}\sum_{i=1}^n h_{ij} \mathbf{x}_i$$
   *(взвешенное среднее объектов выборки с весами $h_{ij}$)*.
3. **Ковариационные матрицы:**
   $$\mathbf{\Sigma}_j = \frac{1}{N_j}\sum_{i=1}^n h_{ij} (\mathbf{x}_i - \boldsymbol{\mu}_j)(\mathbf{x}_i - \boldsymbol{\mu}_j)^T$$

#### Ограничения на структуру ковариационных матриц $\mathbf{\Sigma}_j$:
В зависимости от сложности геометрической формы кластеров накладываются ограничения:
* **Сферические (Spherical):** $\mathbf{\Sigma}_j = \sigma_j^2 \mathbf{I}$ — кластеры изотропны, имеют форму гиперсфер разного радиуса ($p$ параметров).
* **Диагональные (Diagonal):** $\mathbf{\Sigma}_j = \operatorname{diag}(\sigma_{j1}^2, \dots, \sigma_{jp}^2)$ — эллипсоиды, оси которых строго параллельны координатным осям (предположение о некоррелированности признаков внутри кластера).
* **Полные (Full):** $\mathbf{\Sigma}_j$ произвольная симметричная положительно определенная матрица — эллипсоиды произвольной вытянутости и ориентации в пространстве ($\frac{p(p+1)}{2}$ параметров на кластер).

## 3. Жёсткая (Hard) и мягкая (Soft) кластеризация

Кластеризация разделяется по характеру отображения объектов на множество кластеров:

### 3.1. Жёсткая кластеризация (Hard Clustering)
Каждый объект однозначно приписывается **ровно к одному** кластеру:
$$c: \mathcal{X} \to \{1, \dots, k\} \quad \text{или} \quad \mathbf{z}_i \in \{0, 1\}^k, \quad \sum_{j=1}^k z_{ij} = 1$$
* Границы между кластерами являются жесткими поверхностями (например, клетки Вороного в $k$-means).
* **Недостаток:** Отсутствует мера уверенности отнесения объекта. Объект, лежащий точно на границе между двумя кластерами, принудительно отдается одному из них.
* *Примеры:* $k$-means, агломеративная кластеризация, DBSCAN.

### 3.2. Мягкая (вероятностная / нечёткая) кластеризация (Soft Clustering)
Каждый объект принадлежит **каждому** кластеру с некоторой вероятностью (степенью принадлежности):
$$\mathbf{h}_i = (h_{i1}, \dots, h_{ik})^T \in [0, 1]^k, \quad \sum_{j=1}^k h_{ij} = 1$$
где $h_{ij} = \mathbb{P}(C_j \mid \mathbf{x}_i)$ — апостериорная вероятность принадлежности объекта $\mathbf{x}_i$ кластеру $j$.
* Позволяет моделировать пересекающиеся кластеры и выражать неуверенность модели в точках перекрытия плотностей.
* *Переход к жесткой кластеризации (Defuzzification):* при необходимости класс выбирается по правилу максимума апостериорной вероятности (MAP): $c(\mathbf{x}_i) = \arg\max_j h_{ij}$.
* *Примеры:* EM-алгоритм (GMM), Fuzzy $C$-Means.

## 4. Сравнение алгоритмов $k$-means и EM (GMM)

### 4.1. Математический предельный переход: $k$-means как частный случай EM
Рассмотрим GMM с одинаковыми априорными вероятностями $\omega_j = \frac{1}{k}$ и сферическими ковариациями $\mathbf{\Sigma}_j = \sigma^2 \mathbf{I}$.
Апостериорная вероятность на $E$-шаге:
$$h_{ij} = \frac{\exp\left(-\frac{\|\mathbf{x}_i - \boldsymbol{\mu}_j\|^2}{2\sigma^2}\right)}{\sum_{s=1}^k \exp\left(-\frac{\|\mathbf{x}_i - \boldsymbol{\mu}_s\|^2}{2\sigma^2}\right)}$$

Если устремить дисперсию шума к нулю ($\sigma^2 \to 0$):
$$\lim_{\sigma^2 \to 0} h_{ij} = \begin{cases} 1, & j = \arg\min_s \|\mathbf{x}_i - \boldsymbol{\mu}_s\|^2 \\ 0, & \text{иначе} \end{cases}$$
Мягкое вероятностное распределение вырождается в жесткий индикатор (функция $\operatorname{softmax}$ переходит в $\arg\max$). 
Формула для $\boldsymbol{\mu}_j$ на $M$-шаге $\boldsymbol{\mu}_j = \frac{\sum h_{ij}\mathbf{x}_i}{\sum h_{ij}}$ превращается в простое выборочное среднее точек, ближайших к $j$-му центру.
**Вывод:** Алгоритм $k$-means является предельным случаем EM-алгоритма для сферических гауссиан при стремящейся к нулю дисперсии компонентов.
